How It Works

  • Enter a complete news article.
  • The text is processed using NLP.
  • TF-IDF converts the text into numerical features.
  • Logistic Regression analyses the features.
  • The system predicts Real or Fake News.
  • A confidence score is displayed.
  • Low-confidence results are marked as Uncertain.
Note: This is a machine learning prediction system. Please verify important news using trusted sources.
