# Fake News Detection System

## Project Overview

This project detects whether a news article is likely to be Real News or Fake News using Natural Language Processing (NLP) and Machine Learning.

## Objective

To build a machine learning-based system that classifies news articles as Real or Fake.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Flask
- HTML
- CSS

## Project Workflow

Dataset → Preprocessing → TF-IDF → Logistic Regression → Prediction → Flask Web Application

## Features

- News article input
- Fake/Real news prediction
- Confidence percentage
- Simple web interface
- NLP-based classification

## Model Performance

- Accuracy: 99%
- Precision: 99%
- Recall: 99%
- F1-Score: 99%
